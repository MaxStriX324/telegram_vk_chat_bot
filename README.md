# telegram_vk_chat_bot — общий чат-бот Telegram и ВКонтакте

Ранний проект чат-бота, рассчитанного на работу с Telegram и ВКонтакте с общей базой данных. Репозиторий представляет историческую разработку, а не готовый подтверждённый пакет для развёртывания.

## Назначение

Один набор данных для ответов бота в двух каналах: Telegram и сообщество ВКонтакте. Такой подход позволяет развивать логику ответов отдельно от конкретного мессенджера.

## Подтверждённая конфигурация

В репозитории есть `settings.ini` со следующими секциями и ключами:

```ini
[VK]
token=ваш_токен_сообщества
publik=идентификатор_сообщества

[TELEGRAM]
token=ваш_токен_бота

[BD]
path=database.db
```

- `VK.token` — токен сообщества VK.
- `VK.publik` — идентификатор сообщества (**ключ действительно называется `publik`**).
- `TELEGRAM.token` — токен Telegram-бота.
- `BD.path` — путь к общей базе данных; по умолчанию `database.db`.

## Подготовка к запуску

1. Получите токен Telegram-бота и токен сообщества ВКонтакте с необходимыми правами.
2. Настройте `settings.ini` в локальной рабочей копии.
3. Перед первым запуском установите актуальную точку входа и зависимости по исходным файлам проекта и подготовьте структуру базы данных. **Готовая воспроизводимая команда установки в существующем README отсутствовала, поэтому здесь она не заявляется без проверки.**
4. Тестируйте на отдельных тестовых ботах/сообществах, не подключая сразу к рабочим чатам.

## Безопасность и ограничения

`settings.ini` является отслеживаемым конфигурационным файлом. Не публикуйте реальные токены в Git; при эксплуатации рекомендуется использовать переменные окружения или локальный неотслеживаемый конфиг. Секреты, случайно попавшие в историю Git, необходимо перевыпустить.

**Статус: legacy / требуется аудит.** Поведение реального запуска, версии зависимостей, схема базы и актуальная совместимость с Telegram Bot API и VK API не подтверждены. Этот README намеренно не приписывает проекту неподтверждённые функции.
